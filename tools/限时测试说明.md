# 60 秒分流测试

1. 连接 VPN 并启用虚拟网卡。在状态卡的「VPN 网卡」中选好出口，也可以使用「星云自动识别」。勾选要试用的应用，保持分流总开关关闭。
2. 展开状态卡的「连接详情」，点击「试用当前选择 60 秒」。也可以双击同一目录下的「60秒测试.cmd」。两种入口都使用已保存的应用选择。请使用当前 Windows 账户授权。
3. 等窗口提示「测试分流已启用」，再用已选的浏览器打开一个新连接。原有应用选择不会被更改。

独立计时器先就绪，再启动测试分流。默认 60 秒包含启动时间。到期会停止本次测试并核对恢复情况，所以清理可能多花几秒。关掉测试窗口后仍按原定时间停止。测试使用已保存的 VPN 网卡与该客户端当前连接的节点。

如果只想运行 30 秒，也可在此文件夹的普通 PowerShell 中执行：

```powershell
.\SessionWatchdog.ps1 -Seconds 30
```

如当前已有分流会话或待恢复的网络设置，测试会在启用前停止。结果保存在 `%LOCALAPPDATA%\AstralSplit\timed-tests\<测试编号>\finished.json`。其中 `ready` 表示分流曾启用，`baselineVerified` 表示恢复情况已核对；这两项都不代表浏览器最终通过了某个节点。若提示恢复未确认，请按提示检查主程序的「恢复网络」。
